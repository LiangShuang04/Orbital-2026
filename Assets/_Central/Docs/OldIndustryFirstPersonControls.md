# OldIndustry First Person Walker

Target scene: `Assets/Scenes/demoMainScene.unity`

Controls:

- `WASD` or arrow keys: move
- Mouse: look
- `Left Shift`: sprint
- `Space`: jump
- `Left Ctrl`: crouch
- `Esc`: toggle cursor lock
- `F`: toggle between FPS walker and OldIndustry FreeCamera

Setup menu:

- `Tools > Old Industry > Setup First Person Walker In Demo Scene`
- `Tools > Old Industry > Setup First Person Walker In Open Scene`

The setup keeps the old camera in the scene, disables it by default, and makes the new FPS camera the only active `MainCamera` with one active `AudioListener`.
